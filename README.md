# AIPINTAI · AI平台网

**面向中文用户的 AI 工具导航、行业资讯与知识平台。**

想找一款能用在工作里的 AI 工具，或弄清一个新出现的 AI 概念？AIPINTAI 把工具入口、中文解读和行业动态放在一个地方，方便个人用户、开发者和小团队按需求查找。

[访问官网](https://www.aipintai.com/) · [提交 AI 工具](https://www.aipintai.com/?formid=1&plugin=nciaer_form) · [反馈与建议](https://github.com/hogoai/aipintai.com/issues)

## 如何参与

- **推荐工具** · 欢迎提交你开发或使用过的 AI 产品。请附上官网链接，简要说明它能解决什么问题。
- **反馈问题** · 如果发现失效链接、分类错误，或有希望增加的内容，欢迎在 [GitHub Issues](https://github.com/hogoai/aipintai.com/issues) 留言。附上页面链接可以帮助我们定位。
- **关注项目** · 如果 AIPINTAI 对你有帮助，欢迎给仓库点个 Star，方便下次找到它。
- **合作交流** · 产品收录与其他合作可通过官网的[合作咨询](https://www.aipintai.com/bd.html)页面联系。

## English overview

**AIPINTAI** is a Chinese-language AI tools directory and knowledge site. It helps readers discover AI tools by use case, follow industry news, and explore topics such as large language models, AI agents, and AI hardware.

This repository is the project's public introduction and feedback hub. [Visit AIPINTAI](https://www.aipintai.com/) or [share feedback on GitHub](https://github.com/hogoai/aipintai.com/issues).
